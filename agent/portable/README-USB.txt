CLAUDE IT TECHNICIAN - PORTABLE AGENT (for the computer's owner)

What it is: a small program the technician asks you to run. It lets the technician work on THIS computer
only while its window is open, and only for what you allow.

How to run:  double-click start-agent.bat and answer the questions.
  1. Read the 8-digit pairing code AND the fingerprint shown in the window to the technician.
  2. The technician must confirm both match on their screen.
  3. To stop at any time: type  d  and press Enter, press Ctrl+C, or close the window.

What it never does: install itself, start with Windows, hide, copy passwords/tokens, or accept connections
from the public Internet. The session ends by itself after the time you chose. When the window closes,
nothing is left behind.

Note: Windows does not run programs from USB drives automatically, so you always start it yourself.
Your security software may ask for confirmation; if it blocks the program, do not bypass it - tell the technician.
